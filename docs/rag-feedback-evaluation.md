# 问答反馈与离线评测

## 回答反馈

聊天页的助手回答完成后可标记“有帮助”或“没帮助”。同一用户对同一条助手消息只保留一个当前选择；再次点击已选项会撤销，切换另一项会更新原反馈。反馈写入 PostgreSQL，并随消息或用户删除而级联清理。读取历史对话时只返回当前用户自己的反馈状态。

接口：

- `POST /api/conversations/messages/{messageId}/feedback`
- 请求体：`{"vote": 1}` 表示有帮助，`{"vote": -1}` 表示没帮助，`{"vote": null}` 表示撤销。
- 只接受当前用户自己会话中的助手消息；不接受用户消息、其他用户消息或不存在的消息。

## 固定评测集

管理员从“管理后台 → 问答评测”选择知识库并运行固定的 6 道问题。评测题集与期望来源、证据短语保存在 `backend/bootstrap/src/main/resources/evaluation/rag-smoke-set.json`，通过版本号管理；更新题目时应同步更改版本号。

评测不生成回答，也不调用 Chat 或 Rerank。每道问题直接执行向量和关键词召回、RRF 融合及现有证据阈值过滤，再与标注来源及证据短语比较。它使用当前配置的 Embedding 服务；无外部 Embedding 配置时使用项目的本地演示向量。评测适合比较同一环境、同一数据集下检索配置的变化，不是生成答案质量或真实供应商质量测试。

指标：

- **来源 Hit@1**：期望来源是否排在第一位。
- **来源 Recall@6**：期望来源是否出现在前 6 条结果中。
- **MRR@6**：首个期望来源排名倒数的平均值。
- **证据词覆盖率**：召回片段中命中的标注证据短语比例。匹配时忽略大小写、全角差异和空白。

当前题集覆盖年假申请、安全事件上报与工单字段、VX-700 工单根因与升级条件。运行前需在所选知识库中上传与这些题目相对应的演示资料；缺少某份资料时，该来源相关题目的检索分数会自然下降。

接口：

- `GET /api/admin/evaluation/cases` 返回题集和版本。
- `POST /api/admin/evaluation/run`，请求体 `{"knowledgeBaseId":"<UUID>"}`，返回每道题的命中来源、证据词、召回片段和汇总指标。
- 两个接口均要求管理员权限。
